# KU_FINAL 嵌入式相控阵通信系统与 FPGA/FreeRTOS 软硬协同全景教程

> **适用对象**：嵌入式软件工程师、FPGA 开发初学者、通信与相控阵雷达系统研发人员。  
> **目标工程**：`KU_FINAL`（基于赛灵思 Xilinx Zynq-7000 SoC，型号 `xc7z020clg484-2`）。  
> **工具与内核版本**：Vivado Design Suite 2018.3 / Xilinx SDK 2018.3 / FreeRTOS v10.0.0 (`freertos10_xilinx_v1_2`)。

## 新手极速上手心法

1. **“软硬界限”牢记心中**：
   - 软件（C语言代码）只认**内存地址**与**指针**；
   - 硬件（Verilog代码）只认**时钟上升沿**与**电平翻转**；
   - AXI 总线是连接两个世界的跨界“翻译官”。
2. **“先跑通，再完善”**：
   - 先用一键脚本跑出 `system_wrapper.bit` 和 `GT2001.elf`；
   - 接好串口看开机字符串（`KU_FINAL SERIALFIX`、`GT1002 START`）；
   - 发送测试指令 `$xxTST*00` 验证回显，再深入算法与波形微调。
3. **“改对地方，改错归零”**：
   - HDL 代码**唯一合法修改源**是 `Ku_IP\ip_repo\Ku_TR_SPI_1.0`；
   - C 语言源码**唯一合法修改源**是 `GT2001_0316\GT2001_0316.sdk\GT2001_0324sdk\GT2001`；
   - 硬件平台**唯一有效目标**是 `system_wrapper_hw_platform_0`。
