# KU_FINAL Zynq Project - Gemini Review Set

这是 KU_FINAL Zynq/Vivado 项目的 Gemini 网页端分析版本。

## 内容范围

- `GT2001_0316/`：Vivado 工程、Block Design、IP 配置、应用源码和必要的 SDK/BSP 源码
- `Ku_IP/`：自定义 SPI IP 源码和配置
- `tools/serial_monitor/`：串口监视工具源码
- `learn/`、项目说明和硬件文档

## 未纳入内容

为满足 Gemini 网页端的仓库大小限制，以下内容未纳入：

- Vivado 缓存、运行目录、仿真输出和日志
- `.bit`、`.bin`、`.elf`、`.hdf` 等构建产物
- SDK 调试输出和 IDE 元数据
- PhaseArray 已编译安装包
- 串口工具打包目录
- 大量重复的 Vivado 自动生成 HDL
