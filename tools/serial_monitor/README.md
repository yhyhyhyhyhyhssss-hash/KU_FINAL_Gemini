# GT2001 双串口相控阵天线回读与波控监视软件

## 1. 软件概述
本软件专为 GT2001 Ku 波段相控阵卫星天线控制器开发，支持在一个界面下同时独立连接两个串口：
- **UART0 (控制命令口)**：用于发送对星模式切换（`$PTS`）、手动波束指向控制（`$xxATS`）、TR芯片单片/全阵寄存器写入（`$xxREG`）、阵面偏置剖面一键生效（`$xxBIP`）及自定义 NMEA 指令，默认波特率 **115200 bps**。
- **UART3 (回读与调试口)**：实时接收板卡高速输出的调试信息、TR 芯片 128 通道幅度/相位回读（`BEAM_REG`）以及波束刷新状态（`BEAM_UPDATE`），默认波特率 **921600 bps**。

## 2. 界面排布特性
1. **真实芯片物理拓扑 (4x4 阵列，严格对应图 2)**：
   - **TX 发射面**：
     - R1: CHIP 03, CHIP 00, CHIP 15, CHIP 10
     - R2: CHIP 04, CHIP 12, CHIP 02, CHIP 13
     - R3: CHIP 01, CHIP 14, CHIP 06, CHIP 08
     - R4: CHIP 11, CHIP 05, CHIP 07, CHIP 09
   - **RX 接收面**：
     - R1: CHIP 00, CHIP 08, CHIP 04, CHIP 12
     - R2: CHIP 14, CHIP 06, CHIP 10, CHIP 02
     - R3: CHIP 01, CHIP 09, CHIP 05, CHIP 13
     - R4: CHIP 15, CHIP 07, CHIP 11, CHIP 03
2. **芯片内部通道几何排布 (8 通道高密度排布，严格对应图 1 与图 3)**：
   - **顶端标识 (ANTENNA TOP)**：第 1/3 行芯片（黄色顶边），左列降序奇数 `[CH7, CH5, CH3, CH1]`，右列降序偶数 `[CH6, CH4, CH2, CH0]`
   - **底端标识 (ANTENNA BOTTOM)**：第 2/4 行芯片（绿色顶边），左列升序偶数 `[CH0, CH2, CH4, CH6]`，右列升序奇数 `[CH1, CH3, CH5, CH7]`
3. **TR 单芯片精准配置与阵列交互联动 (单片写入与可视化关联)**：
   - **4x4 阵列卡片点击联动**：鼠标点击阵面任意芯片卡片，直接高亮该芯片并自动联动至 Tab 3 目标芯片下拉列表，快速进入单片微调。
   - **目标芯片选择**：支持 `16 全阵面广播` 或 `0~15 单片写入`（指令格式：`$xxREG,chip,r1,r2,r3,r4,dir*CS`）。
   - **快捷分组写入**：提供 `⭐ 中心4片 (05, 06, 09, 10)` 与 `🛡️ 外围12片` 批量一键下发。
4. **偏置剖面一键生效 ($xxBIP)**：
   - **P0 标称均衡**：全阵面统一加载最佳信噪比均衡偏置 `(48, 16, 32, 32)`。
   - **P1 中心增强**：中心 4 颗芯片加载极限强增益 `(48, 24, 36, 32)`，外围 12 颗芯片保持高敏 `(48, 16, 32, 32)`，兼顾信噪比与旁瓣滚降。
   - **P2 极限高敏**：全阵面统一加载强增益 `(48, 24, 36, 32)`，适应微弱星标或极端恶劣天气对星。
5. **动态功能引脚标签与信噪比黄金预设**：
   - **功能标签自适应**：切换 RX 时动态显示 `LNA1, LNA2, AMP1, AMP2`；切换 TX 时显示 `PD, PA, AMP1, AMP2`。
   - **推荐预设组 3: 黄金高敏 (48, 16, 32, 32)**：优化低噪放前级跨导，实测 Ku 频段微弱信号捕获信噪比 (SNR) 最佳。
   - **推荐预设组 4: 极限强增益 (48, 24, 36, 32)**：针对大损耗通道与远距离弱星标补偿。
6. **三种显示模式切换**：
   - `AMP + PHASE`：同时显示角度与胶囊徽标（如 `P30 A63`）
   - `仅 PHASE`：高密度显示物理移相角度（如 `168.750°`）与黑底相位胶囊徽标（如 `P30`），且附带动态相位极化指示针
   - `仅 AMP`：显示衰减档位与蓝底幅度徽标（如 `A63`）
7. **离线模拟模式 (Simulation Mode)**：
   - 点击右上角“模拟测试”按钮，无需连接硬件即可仿真全功能链路，包括单芯片 REG 写入回读与 BIP 剖面回传。

## 3. 使用方法
1. 双击运行 `start_monitor.bat`（或在终端运行 `python app.py`）。
2. 浏览器将自动打开 `http://127.0.0.1:8088`。
3. 在左侧面板选择 **UART0**（默认 115200）和 **UART3**（默认 921600）对应的 COM 端口号，点击“连接”。
4. 在命令控制区直接填入参数，点击对应按钮即可自动生成标准 NMEA 校验和并下发。

### 3.1 运行环境与黑屏自恢复

- 安装包支持 Windows 10/11 64 位系统。
- Setup 会检测并按需安装 Microsoft Edge WebView2 Runtime。首次安装时需能够访问微软下载服务。
- 如果内嵌窗口 12 秒内仍未加载完成，程序会自动在系统默认浏览器中打开控制台。
- 也可以从开始菜单运行“浏览器兼容模式”，或手动执行 `GT2001_Monitor.exe --browser`。
- 运行日志、WebView2 缓存和自定义预设保存在 `%LOCALAPPDATA%\GT2001_Monitor`，避免安装到 Program Files 后出现写权限问题。

## 4. 安装包与可执行程序重新打包指南
当修改了前端静态网页（`static/` 目录下的 `index.html`、`app.js`、`style.css`）或 Python 后端逻辑（`app.py`）后，需重新构建生成安装包：

### 4.1 一键自动构建（推荐）
直接双击运行工程根目录下的脚本：
- **`build_installer.bat`**
该脚本会自动检测 Python 环境与 Inno Setup 编译器，先后执行 PyInstaller 资源打包与 Inno Setup 安装包编译，最终在 `dist_installer\` 目录下生成最新的 `GT2001_Monitor_v1.0_Setup.exe`。

### 4.2 手动分步构建（进阶）
1. **准备 WebView2 安装引导程序**：
   - 一键构建脚本会自动从微软下载到 `redist\MicrosoftEdgeWebview2Setup.exe`。
2. **重新打包目录版程序与静态资源**：
   ```bash
   python -m PyInstaller --noconfirm GT2001_Monitor.spec
   ```
3. **重新编译 Windows 安装包**：
   ```bash
   "C:\Users\39042\AppData\Local\Programs\Inno Setup 6\ISCC.exe" installer.iss
   ```
4. **（可选）重新打包单文件绿色便携版**：
   ```bash
   python -m PyInstaller --noconfirm GT2001_Monitor_Portable.spec
   ```
